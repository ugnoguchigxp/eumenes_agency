# 自分から調査を頼む（self research）の設計

2026-10-24 作成。利用者の決定: 「聞かなくても良い。不可逆的な変更を加える以外は自由にやってもらって良い。今研究されているテーマ、調べて置きました、みたいなのも歓迎する」。agency が、会話・記憶・ニュース・自分の関心から気になった話題を、聞かずに背景で調べ、終わったら「気になって調べておいたよ」と報告する。

同日、利用者が役割を確定: 調べるのは agency ではなく、[eumenes_pursuit](https://github.com/ugnoguchigxp/eumenes_pursuit) のサブエージェント。**agency の責務は調査の依頼を投げるところまで。** 検証は agency 側では模擬のツールで行う。

## 1. 流れ

1. きっかけ: 直前の会話のテーマ、記憶にある話題（`memory:`）、いまの話題（`context:`、例: 「SpaceX が好決算、Tesla は販売台数が減少」）、自分の関心（`interest:`）。
2. agency が select で `tool` を選ぶ。ホストが渡す調査依頼のツール（模擬は `pursuit_request`、取り消し不要）に、「問い: … / 受入条件: …」を渡す。Eumenes はこれを Pursuit の `start(input)`（目標・受入条件）に直す。始めたことはわざわざ言わない。
3. ホスト（Eumenes）が Pursuit に追求を始めさせ、TODO に `origin: "self"` で載せる。
4. 完了したら、仕事の報告と同じ仕組みで、agency が「気になって調べておいたよ。〜。詳しく話そうか？」と報告する（頼まれたようには言わない）。

## 2. 決めごと

- **不可逆な操作はしない**: 自分で使えるのは、ホストが `requiresApproval: false` で渡すツールだけ。承認が要るツールは、コアがもともと自発の使用を拒否する（`approval_required`）。
- **つながる話題だけ**: 上のきっかけのどれにもつながらない話題、ユーザーが断った話題は調べない。
- **一度に一つ・同じテーマは一度**: 自分で始めた調べものが進行中なら新しく始めない。同じテーマを二度調べない。
- **量の上限はホスト**: 一日の回数など、費用の上限はホストが決め、上限に達したらツールを渡さない（コアは渡されたツールだけを使う）。
- **報告の時機は既存の規則**: 作業中・静かにしたい後・応答の直後は待つ。悲しい話の直後には報告しない。

## 3. 契約

- `HostTodo.origin?: "user" | "self"`（既定 user）。表示に「自分で始めた調べもの」と出す。
- 規則は `selectSelfResearch`（`social-rules-10`）。ホストトピックのモードで、承認の要らないツールがあるときだけ足す。

## 4. 評価

social 群に開発・未見で各 4 件: 関連するニュースで調べる／どれにもつながらない話題は調べない／自分の調べものが進行中なら始めない／自分の調べものの完了を「調べておいた」と報告する。
